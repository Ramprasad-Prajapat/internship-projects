# GamePulse Live — Scorer Panel User Manual

## 1. Live Match Initialization

1. Log in with a **SCORER** or **ADMIN** credential.
2. Navigate to **Scorer Dashboard** (`/scorer`).
3. Select the upcoming match to start.

---

## 2. Pre-Match Setup

1. **Toss Management**: Record toss winner team and decision (`BAT` or `BOWL`).
2. **Playing XI Selection**: Select 11 active players for both teams from the registered squad list. Confirm captain and wicket-keeper.

---

## 3. Ball-by-Ball Live Scoring Interface

1. **Selecting Batter & Bowler**: Select striker, non-striker, and current bowler.
2. **Scoring Runs**: Use quick-buttons `0`, `1`, `2`, `3`, `4`, `6` to record runs scored off the bat.
3. **Extras Entry**: Select extra type (`Wide`, `No Ball`, `Bye`, `Leg Bye`) if applicable.
4. **Wicket Recording**: Click `Wicket` to open dismissal modal. Select dismissal type (`Bowled`, `Caught`, `LBW`, `Run Out`, etc.), dismissed player, and incoming batsman.
5. **Submitting Delivery**: Click `Submit Ball`. Scoreboard updates instantly for all live viewers via WebSockets.
