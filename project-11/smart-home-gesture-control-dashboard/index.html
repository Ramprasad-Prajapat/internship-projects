ℹ️ About This Project

Project Overview

A webcam-based smart home gesture control simulation website. It demonstrates the complete workflow of touchless device control — from camera access to device & room status updates.

Problem Statement

Normal smart home apps require a mobile, remote, voice, or switches. Gesture control gives a touchless and interactive way to control devices.

Solution

The website uses camera input, gesture recognition, stable detection, cooldown and manual backup control to simulate smart home automation.

How It Works

  1. Camera captures the hand.
  2. JavaScript (MediaPipe) detects the gesture.
  3. Gesture is checked for confidence & stability.
  4. Selected device receives the command.
  5. Device and room status update.
  6. Activity log is saved to LocalStorage.

Why Stable Detection Is Needed

Cameras can wrongly detect gestures, so stable detection and cooldown stop repeated/false actions.

Technology Used

  • HTML5
  • CSS3 (Glassmorphism)
  • JavaScript (ES6)
  • WebCam API (getUserMedia)
  • LocalStorage
  • SpeechSynthesis API
  • MediaPipe Tasks Vision (CDN)

Limitations

This is a simulation — real devices are not controlled. Camera accuracy depends on lighting and webcam quality.

Future Scope

ESP32 / Arduino relay control, Firebase database, user login, mobile app, custom gesture training.
