# vocalic-voice-calculator-web-app

**Live Demo:** Deployment pending


A voice-activated cosmic glassmorphic calculator web application allowing users to compute mathematical expressions through continuous speech recognition or interactive tactile on-screen controls, with synthesized voice readout of answers.

## Tech Stack
- Frontend: Semantic HTML5, CSS3 Cosmic Glassmorphism, Vanilla JavaScript
- Speech Recognition: Web Speech Recognition API (continuous speech-to-text)
- Speech Synthesis: Web Speech Synthesis API (TTS with pitch, speed, and accent customization)
- Sound Engine: Native Web Audio API procedural synthesizer for tactile click sounds

## Features
- Continuous vocal arithmetic parser translating spoken phrases ("25 plus 15", "100 divided by 4") into math expressions
- Text-to-Speech (TTS) voice announcements of computed results
- Tactile calculator keypad with responsive micro-animations, glowing borders, and sound effects
- Calculation history log sidebar with instant reload of previous expressions
- Full physical keyboard input support for standard number pad calculation
- Voice customization panel (voice selector, speed slider, pitch controls)
