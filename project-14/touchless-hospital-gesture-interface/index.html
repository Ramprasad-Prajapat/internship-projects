Core Algorithms

Aura OS maps hand coordinates to screen dimensions using linear scale ratios, applying customized exponential smoothing to damp wrist coordinates jitter:

x_smooth = x_prev + (x_target - x_prev) * smoothing
y_smooth = y_prev + (y_target - y_prev) * smoothing
