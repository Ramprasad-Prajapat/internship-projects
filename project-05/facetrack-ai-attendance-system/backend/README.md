# Backend API Folder (Placeholder)

This folder is a placeholder for a future server/API (e.g. Express.js) and is **empty by design**.

The application currently runs **frontend-only in mock mode** — there is no backend and no
Firebase runtime connected. All data and auth are mock (reactive `localStorage` store in
`frontend/src/services/`). A real backend can be added later by replacing the mock
service layer with real API/Firebase calls behind the same function shapes.
