# mental-wellness-chat-and-meditation-platform

**Live Demo:** Deployment pending


An emotional wellness companion and mental health support web application designed to help individuals navigate feelings, track mental wellness trends, and practice mindfulness through guided meditation.

## Tech Stack
- Frontend: Semantic HTML5, CSS3 Glassmorphism (Dual Light/Dark Theme), Vanilla JavaScript
- Data Visualization: Chart.js for mood history tracking
- Sound Engine: Native Web Audio API synthesizer for meditation bells and ambient tones

## Features
- Conversational emotional support chat interface with empathetic responses and guided prompts
- Guided breathing and mindfulness meditation timer with audio chimes and cycle counters
- Daily mood logger with interactive Chart.js weekly and monthly trend visualizations
- Anonymous community wellness feed for sharing supportive thoughts and reflections
- Immediate emergency crisis hotline and professional support contact directory
- Administrative analytics overview for platform wellness engagement
